# Provenance

The new working repository begins at the accepted post-application baseline.

Earlier repositories remain source evidence. This directory records which identities were consulted and which artifacts were admitted into the working baseline.

## Required source identity

For admitted legacy material record, where applicable:

- source repository;
- source branch;
- source path;
- exact source commit;
- original role;
- admission decision;
- whether the content was copied unchanged, rewritten, or represented only by a current navigation/synthesis document.

## Admission outcomes

- `ADMIT AS-IS`
- `ADMIT AFTER REWRITE`
- `ARCHIVE ONLY`
- `REJECT FROM CURRENT BASELINE`

A useful idea can be preserved in the future archive without becoming current instruction.

## Historical boundary

Early public demos, Sarah prototypes, research demonstrations, transfer staging, superseded plans, and rejected implementation candidates are not current merely because they remain accessible.

The future archive preserves history. This repository preserves current working meaning.
