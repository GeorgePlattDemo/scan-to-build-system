Use these meanings in new application work:

- `DefinitionReviewRecorded` = exact-definition review record; not commercial submission, purchase, Store acceptance, payment, reservation, governed authorization, production authorization, machine readiness, or Cycle Start.
- `UnresolvedDefinitionAcknowledged` = acknowledgment of an unresolved/incomplete state; not support or resolution.
- Store `SUPPORTABLE` = favorable result under the exact Stage-2 checks/scope; not comprehensive physical approval or governed acceptance.
- `BudgetaryEstimate` / Q = Store budgetary result; not commercial quotation or payable total.
- modeled cycle = reference/calculated duration; not measured production time.
- current Store answer = applicable to exact candidate/revision/request/attempt; not automatically live, freshly queried, reserved, or commercially binding.
- Store, governed, commercial, Cell and local-controller meanings remain separate.

Durable wire/type identifiers should not be renamed merely to improve English. Clarify their scoped meaning instead.
