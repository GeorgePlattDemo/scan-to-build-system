## Application guardrails

- `DefinitionReviewRecorded` = exact-definition review record; not commercial submission, purchase, Store acceptance, payment, reservation, production authorization, machine readiness, or Cycle Start.
- `UnresolvedDefinitionAcknowledged` = acknowledgment of an unresolved/incomplete state; not support or resolution.
- Store `SUPPORTABLE` = favorable result under the exact implemented Store checks/scope; not comprehensive physical approval or production authorization.
- `BudgetaryEstimate` / Q = Store budgetary result; not automatically a commercial quotation or payable total.
- modeled cycle = reference/calculated duration; not measured production time.
- current Store answer = applicable to the exact candidate/revision/request/attempt; not automatically live, freshly queried, reserved, or commercially binding.
- Store, commercial, machine-readiness, controller, and physical-execution meanings remain separate.
- durable wire/type identifiers should not be renamed merely to improve English; clarify the scoped meaning instead.
