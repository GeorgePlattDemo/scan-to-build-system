# External processing rule (0.1)

M1 contains no model calls. Preserve that condition.

When a later milestone introduces model-assisted interpretation, classification, retrieval, or explanation:

No model call may occur on the authorization or safety-gate path. A model is a processor of disclosed information, not an authority.

Before content crosses from holder-controlled infrastructure to an external processor, the system must determine and record:

- permitted purpose
- minimum necessary content
- recipient or provider
- model identity where known
- retention treatment
- provider-improvement or training treatment
- applicable permission
- unresolved terms

Required distinctions: local or holder-controlled processing; external processing; model output; source evidence; observation; recommendation; authorization.

Unknown external-processing or retention terms remain unresolved and may require refusal or a lower-disclosure route.

Contractual “zero data retention” does not automatically resolve caching, logs, subprocessors, backups, employee accounts, abuse monitoring, derived outputs, or tool calls.

This document does not select a model provider, hosting architecture, or open-source model.
