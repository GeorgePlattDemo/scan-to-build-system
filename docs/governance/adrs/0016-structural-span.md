# ADR-0016 Structural span is not evaluated in M1

Status: accepted

Context: No attributed structural rule is loaded.

Decision: Record STRUCTURAL_SPAN_NOT_EVALUATED. Do not invent modulus or deflection.

Consequences: Geometric fit may pass while structural remains unresolved.

Does not establish: code compliance.

Affected: G-SPAN-SHELF, WorkPacket, OutcomeRecord
