The canonical migration therefore does **not** copy `system-build-current.html` or the Review root shell into System as a second application.

The smallest safe direction is:

```text

  → System project library
  → System project identity + registry
  → native System project OR bounded Review project child adapter
  → identified definition / revision
  → System Store / commercial / completion boundaries where applicable

```

A child may preserve its own mature project-specific definition behavior. The parent owns project identity, legal stage routing, current-child selection, and durable custody of admitted child snapshots. A child does not gain Store, commercial, machine, or execution authority from being hosted.
