# Scan-to-Build / Home as a Twin — Public Review Package

Public review artifact · simulation only · no live machine control · no production claim.

U.S. Patent Nos. 9,720,401 and 10,768,609, held by 3D Solutions LLC, provide issued context for review. Publication of this repository grants no license. See [NOTICE.md](docs/NOTICE.md).

Scan-to-Build is the anchor vertical: a homeowner defines a wood-based project, the project becomes a governed WorkPacket, unsupported work is refused, eligible work is routed, and the result returns to the homeowner's record.

Home as a Twin is the owner-held record layer that lets that path accumulate across projects instead of starting over each time.

Together, Scan-to-Build and Home as a Twin test a broader proposition: that a person's resolved intent and verified context can travel through commerce and fulfillment as a governed, portable definition, rather than being inferred or rebuilt at every handoff.

Rendered demonstration site: https://georgeplattdemo.github.io/scan-to-build-review/

The site contains the interactive demonstrations, verticals matrix, and windows worked proof. The documents below are the review package behind it.

## Running the proof layer

The proof layer, item 8, is a single HTML review artifact. GitHub displays `.html` files as source, so it is best opened through the [rendered demonstration site](https://georgeplattdemo.github.io/scan-to-build-review/) or downloaded from this repository and opened locally in any modern browser.

No installation or build step is required. The file is offline and dependency-free. Its workflow, gates, modeled execution reports, and verification checks run entirely within the page and do not connect to outside systems.

## Why this package exists

Home improvement is built on fragmented custody. Measurements, product specifications, machine limits, labor scopes, pricing inputs, and installation records live in separate private silos.

Every project becomes a first-time event. The home is re-measured, re-explained, re-priced, and reinterpreted by each actor in the chain.

As more research and decision-making occurs in private AI-assisted conversations, businesses may see the transaction without seeing the reasoning, constraints, and choices the customer has already resolved.

The problem is not a lack of technology. It is a lack of shared language, controlled handoffs, and governed record-keeping.

The issued patents define a consumer-to-fabrication foundation connecting customer interaction, project definition, processor-calculated pricing, CAD/CAM instruction generation, dimensional- and sheet-stock fabrication, operator action, labeling, assembly information, and local project release.

The present architecture adds owner-held custody, WorkPackets, validation and refusal, material governance, routing, scoped consent, versioned evidence, outcome return, and portable export. Home as a Twin gives the path memory by returning each completed result to the homeowner's record.

The review sequence follows that structure. It begins with the homeowner journey, defines the architecture and shared vocabularies, shows the packet that carries them, traces the operating path, and runs a representative workflow in the browser. It then walks backward through the 33 issued claims before turning to controlled improvement, institutional study, and future technical or legal questions. It closes with published work by other researchers, so the questions raised here can be read against the field they sit in.

The package makes the proposed path from human intent toward physical outcome explicit, governed, auditable, and owner-held, and exercises that path in the browser.

The documents define the language and boundaries. The WorkPackets carry them. The roadmap establishes the operating order. The proof layer makes that order inspectable. The issued-claims walkthrough shows where the chain began and where the present governance layer extends it. Read together, the artifacts form one review sequence: define the terms, carry them through the packet, exercise the operating order, trace the issued foundation, and frame what comes next.

## Review boundaries

It is not a production deployment, machine controller, live SKU service, operational pricing engine, commissioned fabrication cell, safety certification, or field pilot.

- live machine control or physical execution;
- production or deployment readiness;
- validated commercial economics;
- real supplier, inventory, financing, or fulfillment integrations;
