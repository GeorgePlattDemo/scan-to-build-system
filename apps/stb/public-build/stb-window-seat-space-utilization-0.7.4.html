Where the drawing and your tape disagree, neither is promoted. You say which one controls. The configurator starts from this drawing because it is the supplied project intent — it does not start from Store stock.

Some numbers are about taste, not fit. Where the top lands is your call. So is lining a shelf up with something already in the room. We keep those choices separate from the measurements they sit within. Anything you pick here is carried as a preference — it travels with the project and it does not cut a part.

What’s off stays on the record. A sloping floor, a bowed wall or an obstruction belongs here too. Recording it does not mean we have corrected it. Anything you pick here is carried as supporting context.

Don’t know a number yet? Mark it “Needs checking.” You can keep your work and come back. A number that still needs checking stops the project only where the current definition actually depends on it — we’ll say which ones those are.

BUILD GUIDE · TECHNICAL

Capture · evidence & authority

KEEP THE SOURCEScan, photo, drawing or plan remains retained evidence. Do not overwrite it with extracted facts.
CUSTOMER DRAWING CONTROLS INTENTThe supplied elevation governs the visible product relationship. Translation may not redesign it.
SOURCE ≠ OBSERVATIONA file is evidence. A dimension or condition read from it is a separate attributable observation.
OBSERVATION ≠ VERIFIEDReading or extracting a value does not promote its authority.
SOURCE ≠ STATUSWhere a fact came from is separate from whether it is controlling, supporting or still needs checking.
NO SILENT PROMOTIONA number visible in an image stays context until the holder explicitly gives it controlling status.
CONFLICTS STAY VISIBLEPreserve competing values and their sources. Do not auto-pick, average, round away or let AI decide the winner.
UNKNOWN STAYS UNKNOWNNo filler values. No “reasonable” dimensions inserted to complete the form.
ASK ONLY WHAT CHANGES THE DEFINITIONA question appears because an unanswered responsibility can change the project, not because the data might be useful later.
CONTEXT DOES NOT CUT WOODSupporting facts may travel with the record without becoming fabrication truth.
ONLY CONSEQUENTIAL GAPS BLOCKMissing context is not an artificial gate. Block only where the active definition depends on the missing answer.
THE SPACE IS THE REFERENCEThe project is defined inside the observed place; the place is not silently changed to fit the project.
HOLDER OWNS INTENTThe customer can state and confirm project intent. That does not establish Store, engineering or machine truth.
NO ENGINEERING AT INTAKENo span rules, load claims, fastener prescriptions, anchorage advice or structural conclusions are invented here.
RECEIVE BROADLY · COMMIT NARROWLYKeep what the person brings. Promote only what has an explicit basis and role.
CHAIN OF CUSTODYSource → observation → customer choice → derived definition. Each step stays attributable.

BUILD GUIDE · TECHNICAL
Definition · Store · machine boundary


    
CUSTOMER ELEVATION GOVERNSThe supplied product drawing controls visible relationships. The configurator translates it; it does not redesign it.

    
DRAWING IS A PROMISEEvery visible feature must trace to the same definition, occurrences, material demand and requested work.

    
THREE TOP-LEVEL MODULESASM-LEFT · ASM-CENTER · ASM-RIGHT. Do not invent a fourth assembly to simplify implementation.

    
CENTER IS COMPLETEUpper storage · window opening · seat · lower cubbies remain one full-height center module.

    
SOLID BOARD ONLY¾-in finished solid-board demand. No plywood, MDF, particleboard or glued-panel shortcut.

    
ONE NUMBER ONCEEnter the controlling fact once; derive every downstream consequence from that same revision.

    
STABLE OCCURRENCE IDENTITYFinished parts remain individually traceable through revision. A replacement can point to one exact occurrence.

    
PART ≠ BOARD RUNA finished 14-in-deep part may require multiple physical board runs. Preserve both truths.

    
NO JOINERY INVENTEDNo dado, groove, rabbet, mortise, tenon, pocket hole or other joinery unless this project explicitly demands it.

    
NO DADOS HEREDado capability elsewhere does not create Window Seat demand.

    
NO ENGINEERING INVENTEDNo structural adequacy, deflection, anchorage, connection, installation or load claims.

    
NO 4-FT SPAN RULENo generic shelf/seat span heuristic is introduced. The app is not a substitute engineer.

    
EXCLUSIONS STAY EXPLICITConnection design · fastener selection · installation · finishing · structural evaluation remain outside this definition.

    
INTENT BEFORE INVENTORYThe project states what is required. Store answers whether and how its current offering can satisfy it.


    
CUT TO FINISHED LENGTHSquare crosscut follows the defined finished board-run length.

    
MILL EDGE TO FINISHED WIDTHBounded longitudinal edge milling finishes one board to the project-required width.

    
MILL ≠ RIPOne parent remains one finished board. Retain one reference/fence edge; machine the opposing edge.

    
FULL OFFERED LENGTHNo 60-in machining cap and no unsupported-span rejection. Edge milling may run the full offered parent length.

    
SUPPORT IS STORE HANDLINGThe yard supplies appropriate infeed/outfeed/material support for stock it offers; support need does not invalidate demand.

    
12-IN STOCK-WIDTH LIMITCurrent reference maximum parent stock width for this bounded D-001 path.

    
1.0-IN MAX EDGE REMOVALCurrent reference maximum total longitudinal edge reduction.

    
0.375-IN DEPTH / PASSCurrent modeled mill depth per pass.

    
CHIP-LOAD FEED CLOCK3/8-in · 2-edge · 18,000 RPM reference: Pine 243 IPM; Poplar / Oak / Cherry 216 IPM. Declared reference, not commissioned production.

    
3/16-IN FACE SPOTFixed 0.1875-in diameter. Customer specifies occurrence, face/location, offset, depth and quantity. Not a finished larger hole.

    
HARDWARE IS MERCHANDISEOptional Store packs may be selected and priced separately. Hardware choice is not connection engineering.

    
NO CONTROLLER OUTPUTThe app/Store do not emit G-code, controller dialect, machine coordinates or remote motion commands.


    
MATERIAL REQUIREMENT ≠ SKUSpecies/form/finished geometry are project demand. Store resolves them to offerings.

    
NO SILENT SUBSTITUTIONShortage or missing width never changes species, dimensions or product intent behind the customer's back.

    
STOCK SHORT ≠ BAD DEFINITIONAvailability is a Store answer. Known demand and known price remain visible.

    
NOT OFFERED IS DEMAND INTELLIGENCEA missing parent width is a named assortment gap — useful for stocking, sourcing or special-order decisions; never synthesize a SKU to make the screen green.

    
PRICE ≠ CAPABILITYA material can be priced while a service is unresolved, and a supported operation can exist while stock is short.

    
KNOWN COST STAYS KNOWNDo not erase identified material cost merely because another service component is unpriced.

    
KNOWN REFERENCE SELLING BASIS ≠ QUOTEFixture prices and modeled recovery are budgetary/reference evidence, not a seller-of-record commercial offer.

    
STORE ANSWERS STAY SEPARATEMapping · price · availability · process capability · unpriced services · authority are different states.

    
REVISION BEFORE ANSWERChange the definition and the prior Store answer becomes historical; it does not silently follow the new revision.


    
CONFIRMATION ≠ ORDERHolder confirmation freezes intended definition only.

    
ORDER ≠ PAYMENTCommercial agreement and payment evidence remain separate.

    
PAYMENT ≠ ALLOCATIONPaying does not prove material has been reserved.

    
ALLOCATION ≠ PRODUCTION RELEASEReserved material does not authorize fabrication.

    
STORE SUPPORT ≠ MACHINE READYStore supportability does not establish local reference, guards, interlocks, tooling or readiness.

    
MOTOR POSITION ≠ WOOD POSITIONAxis/roller motion does not by itself prove the workpiece retained the required reference.

    
WORKPIECE REFERENCE IS LOCALPhysical reference, retention and any POSITION_VALID condition belong at the commissioned cell.

    
MACHINE READY ≠ CYCLE STARTReadiness and the human/local act that starts motion are distinct states.

    
CYCLE START IS LOCALNo network path or Store answer may remotely create Cycle Start.

    
NETWORK IS NOT THE SAFETY LOOPNetwork may carry identity/status; local controls own stopping and interlocks.

    
REFERENCE ≠ COMMISSIONEDModeled capability is useful evidence, never a claim that a physical machine has been accepted for production.

    
NO BLOOD ON WOODNo convenience, price, schedule or UI state outranks local physical safety.
