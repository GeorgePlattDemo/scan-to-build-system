# Sheet Machine Engineering

This folder will hold the detailed current sheet-machine build record.

Start with `../../staging/SHEET-MACHINE-STAGING-0.1.md`.

## First document

Create `SHEET-MACHINE-BUILD-0.1.md` after the first bounded sheet capability and physical starting architecture are selected.

Use these sections:

1. first research function and why it is useful;
2. physical frame/support/reference concept;
3. sheet handling and workholding;
4. what moves: sheet, tooling platform, or both;
5. tool receiver / saw / router / drill requirements;
6. depth/reference method;
7. actuation candidates;
8. sensing candidates;
9. open/off-the-shelf controller candidates;
10. local I/O and lowering boundary;
11. safety functions and professional review dependencies;
12. candidate BOM with status, source and reason;
13. patent feature correspondence;
14. bench/dry-run/powered test sequence;
15. measured results;
16. refusal/failure cases;
17. Store-visible capability declaration, if earned;
18. unresolved register.

Do not assume S-001 must reproduce every patent mode. Build only the bounded functions justified by the research objective.

Classify important statements using `../DETAIL-CLASSIFICATION.md`.
