# S-001 Mode-2 Reference Architecture 0.1

**Status:** REFERENCE architecture for the callable Mode-2 Store offering, plus the next published curve family  
**Store offering now:** `SHEET_MODE2_STENCIL_V1`  
**Next envelope family:** `SHEET_MODE2_ARCHED_APERTURE_V0` (documented here; not yet a second Store request type)  
**App definition now:** `sheet.mode2.stencil.v1`  
**Physical status:** NOT CLAIMED

This ties Mode-2 Store capacity to the disclosed moving-sheet architecture so “curvilinear” can be true of a machine, not only of a flag.

## 1. App definition

### Already implemented

User may require:

- listed sheet SKU;
- `STRAIGHT_RECT` or `CURVILINEAR_OUTLINE`;
- blank L and W with units;
- tab count ≥ 1;
- route depth with units.

No G-code, spline file, or controller field is accepted.

### Next definition (not yet in the app wire)

The motivating want — 48×72 in blank, 36×36 in square opening, 12 in rise above the square cutline — needs an explicit curve, not the word “curvilinear” on an outer rectangle.

```text
outer      STRAIGHT_RECT
           L = 72 in
           W = 48 in
aperture   CIRCULAR_SEGMENT
           chord = 36 in
           rise  = 12 in
           R     = 19.5 in
tabs       integer ≥ 1 on the aperture
depth      through stock, ≤ published max
```

Until the app carries chord / rise / radius, Store must not pretend the arched hole was evaluated.

## 2. Store envelope

### Live (`SHEET_MODE2_STENCIL_V1`, pin `49d22ce4`)

- parent first 48×96 in;
- min blank 6 in;
- max route depth 0.75 in;
- required ops `ROUTE_PROFILE`, `RETAIN_TABS`;
- profile kinds `STRAIGHT_RECT`, `CURVILINEAR_OUTLINE`;
- process Q unresolved;
- dimensional stock refused.

`CURVILINEAR_OUTLINE` today is a kind flag plus outer L×W. That is weaker than a true segment. Keep the flag. Do not claim it already contains the 19.5 in radius.

### Next family to publish (`SHEET_MODE2_ARCHED_APERTURE_V0`)

Store should later accept or refuse:

- outer rectangle inside the parent;
- one interior `CIRCULAR_SEGMENT` with chord, rise, computed or supplied R, units;
- aperture contained by the outer blank with a later-named margin;
- tab count present;
- refuse free splines, G-code, Mode 3, dimensional stock, missing units.

Neutral packet stays machine-neutral:

```text
LOAD → SEAT → REGISTER → ROUTE_PROFILE → RETAIN_TABS
     → RELEASE → SECONDARY_SEPARATION → LABEL
```

`ROUTE_PROFILE` for this family means: follow the outer rectangle if routed, and follow the circular segment of the aperture. It does not mean “emit toolpath text.”

## 3. Reference kinematic contract

Disclosed Mode-2 relationship. This is the architecture that makes the envelope real.

| Element | Contract |
| --- | --- |
| Sheet | Coordinated **X** axis. The sheet translates forward and reverse on support rollers. |
| Centerline tooling platform | Coordinated **Y** axis. Platform stays at machine centerline in X and travels vertically / in Y. |
| Router | Bounded **Z** plunge and retract. Z is not a drawing axis. |
| Rotating yokes + manipulating rollers | Load path and restraint. Yokes rotate clear to accept the sheet, rotate in, rollers contact the sheet and drive X. |
| Backing / idler relationship | Sheet is held to the backing/idler side so Y = work plane stays true while X moves. |
| Retained tabs | Stencil strategy. Profile is not a through-cut all the way around. Selected attachment points remain. Secondary separation is operator or later. |

Interpolation class for a true curve:

- circular segment in the XY work plane of the sheet;
- generated by **coordinated sheet-X and tool-Y**, not by locking the sheet and walking a gantry in X and Y (that is Mode 3);
- Z down to depth, hold, XY through the segment with tab gaps, Z up.

Lost position, lost seat, or yoke not in the seated state ⇒ stop.

“Start in the center” is a later process choice for an interior aperture (plunge in waste, then join the segment). It is not a Store field and not required by the grant.

## 4. Candidate implementation stack

Minimum plausible **research fixture** stack. Component class, not a purchased BOM. Not an OEM retrofit instruction.

| Function | Candidate class | Plausibility basis | Not implied |
| --- | --- | --- | --- |
| Frame / backing plane | Vertical or near-vertical panel frame with a backing surface and lower support rollers | Established vertical panel-saw architecture (e.g. published Safety Speed H-series / combo frames as *literature*, not identity) | Commissioned S-001 |
| Sheet X drive | Two rotating yoke assemblies, left and right, each carrying servo-controlled manipulator rollers | 10,768,609 B2: at least two rotating yokes; each comprises servo-controlled manipulator rollers moving the sheet forward or reverse | 60 lbf or any force spec |
| Yoke rotate in/out | Geared or actuator-driven rotation between clear and engaged | Same disclosure: yokes selectively rotate into position to hold the sheet against backing plates | Automated load cell |
| Contact / restraint | Rollers press until contact with the sheet against the opposing idler/backing | Specification: pressed until contact is made; sheet forced against idler | Numeric clamp force |
| Tooling platform Y | Platform locked at machine centerline in X; travels on vertical ways | 9,720,401 B2 Mode 2: sheet in X, platform up/down in Y at centerline | Mode 3 X-Y platform walk |
| Y drive | Rack-and-pinion on the vertical ways, or equivalent closed-loop linear drive (ballscrew) of the same role | Specification lists pinion assemblies on the ways | A catalog rack is the claim |
| Y feedback | Motor encoder plus, later, independent linear feedback if slip/backlash fails the segment test | Circular segment needs coordinated feedback, not open-loop hope | Accuracy number |
| Router / Z | Commercial router motor on a plunge slide; mechanical or closed-loop depth stop; collet class typical of panel routers | Grant: routing head; tools need controlled depth; commercial saw/router combos exist (SR5U-class literature) | Floating-head identity with any OEM |
| Controller class | Local coordinated-motion controller capable of two-axis interpolation (sheet-X with tool-Y) plus a discrete Z plunge I/O or third bounded axis | Ordinary CNC interpolation class, used here on the disclosed axis split | App-emitted G-code; brand lock |
| Operator station | Local panel, e-stop, no remote Cycle Start | Existing program rule | Store starts the router |
| Tabs | Planned non-cut spans in the interpolator recipe derived later from tab count | Grant: stencil attachment points; operator severs later | Automated breakout |
| Dust / guard | Enclosure and bit guard before any powered profile test | Safety invariant | Designed geometry on this page |

Safety Speed H5 / SR5U / SpeedWorx pages show that vertical support, material rollers, guided carriages, saw/router combination, plunge/float depth, and powered axis motion exist commercially. They do **not** establish the patented yoke-driven sheet-as-X Mode-2 split. That split is the study delta this stack must remain honest about.

## 5. Unresolved physical parameters

Named holes. Do not invent values.

- yoke contact force;
- roller slip on ½ in sheathing vs sanded plywood;
- minimum tab width and count that still hold a 48×72 in blank with a 36 in aperture;
- interpolation tolerance that still counts as the 19.5 in radius;
- max safe plunge and retract;
- whether outer 48×72 is routed or saw-squared while only the aperture is Mode-2 routed;
- dust extraction at a plunging interior cut;
- guarding for a moving sheet plus a live router;
- electrical / interlock design;
- measured minutes;
- Mode 3 (out of scope).

## What “true curvilinear” requires of this fixture

A research test that would make the Store word honest:

1. Seat a listed 48×96 in sheet.  
2. Command coordinated X/Y through one circular segment (chord 36 in, rise 12 in, R 19.5 in) at crawl speed.  
3. Leave tabs.  
4. Record whether the seated relationship survived.  
5. Do not call that commissioning.

If X and Y cannot hold that segment together, Mode-2 curvilinear is a Store flag only. That result would be valid and would stop widening the envelope.
