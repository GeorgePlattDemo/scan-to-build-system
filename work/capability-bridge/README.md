This folder is the daily bench.

The vault stays where it is. Gold is copied here only after it passes the language gate.

## Objective

Give Store 1 two reference capabilities it can name, describe, and turn into machine-neutral instructions:

1. **Dimensional model** — finished-length / bounded feature work on dimensional stock.
2. **Sheet model (beginning stage)** — one thinner envelope on sheet stock.

The accepted application remains the path that asks the Store.
Atlas donor text is rewritten here before it may steer that path.
A later cell claim may attach only after both offerings exist as Store-callable surfaces.

This packet does **not** commission iron, authorize Cycle Start, or create a tandem cell.

## Language gate

A sentence may live in this folder only if all of the following hold:

1. It names the owning layer: Application, Store, Governed, Machine, or Research.
2. The verb matches evidence: `IMPLEMENTED` / `REFERENCE` / `DOCUMENTED` / `PLANNED` / `NOT CLAIMED`.
3. It does not move authority across a wall.
4. It uses current names: User 1, Store 1, Machine Build *n* (written in full), Board, alcove class, fixture, pin.
5. Review-era exhibit names stay out of current files. Provenance may point at the public exhibit once, in `GOLD-INDEX.md` only.

Protected distinctions (do not collapse):

- candidate definition ≠ governed WorkPacket
- Store `SUPPORTABLE` ≠ governed acceptance
- Store evaluation ≠ fabrication authorization
- user review ≠ order, payment, or Cycle Start
- budgetary Q ≠ quotation
- fixture stock ≠ live inventory
- reference capability ≠ commissioned machine
- patent correspondence ≠ installed capability
- Machine Build *n* ≠ Store/Cell Stage *n*

**NO BLOOD ON WOOD.**
