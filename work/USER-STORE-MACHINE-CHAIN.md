# User / Store / Machine Chain

This note is a navigation aid, not a new authority model.

```text
USER 1
  ↓
APPLICATION
retains evidence → observations → bounded definition/revision
  ↓
GOVERNED BOUNDARY
preserves unresolved/refusal/authority meaning
  ↓
STORE 1
material + stock + capability + economics + sourcing/fulfillment
  ↓
BOUNDED MACHINE-NEUTRAL REQUIREMENT
  ↓
DIMENSIONAL / SHEET / CELL ENGINEERING
local lowering + machine-local state
  ↓
LOCAL CONTROLLER
  ↓
PHYSICAL OUTCOME
  ↓
OWNER RECORD / STORE FULFILLMENT EVIDENCE AS ACTUALLY SUPPORTED
```

Each arrow is a boundary. A downstream success cannot rewrite an upstream fact.
